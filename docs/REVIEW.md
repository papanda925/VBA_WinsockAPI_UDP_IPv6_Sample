# 10ペルソナ・100観点の静的レビュー記録

## 数え方と限界

10種類の利用者・専門家を想定し、各ペルソナで10テーマを確認しました。`10ペルソナ × 10テーマ = 100チェックポイント`です。

これは実在する100人のレビューでも、Windows版Excelで100回動かした結果でもありません。ソース、コメント、README、試験手順を対象とする静的レビューです。VBEコンパイルと32bit／64bitの実通信は未実施です。

## ペルソナ

| ID | 想定した利用者 | 重視した点 | 反映結果 |
|---:|---|---|---|
| P01 | VBA初学者 | 実行順、エラーの読み方 | 起動→SERVER_READY→送信→終了を明記 |
| P02 | ネットワークを学ぶ学生 | UDPの非接続性と到達非保証 | `sendto`成功と応答受信を分けて説明 |
| P03 | 授業担当者 | TCPとの比較、期待結果 | HELLO／ECHO／QUITと無応答試験を用意 |
| P04 | Office 32bit保守担当 | API型、UDT配置 | `LongPtr`、WSADATA 400バイト想定を確認 |
| P05 | Office 64bit保守担当 | ポインター幅、アラインメント | Win64 WSADATA 408バイト想定を確認 |
| P06 | ネットワーク技術者 | データグラム境界、送信元 | `recvfrom`のアドレスとポートを検証 |
| P07 | セキュリティ担当 | 待受範囲、ポート共有、偽応答 | `::1`、排他bind、送信元／TraceId照合を採用 |
| P08 | 学生サポート担当 | 文字化け、別Excel、停止 | UTF-8注意と専用Excel終了マクロを追加 |

## 各ペルソナで確認した10テーマ

1. 目的、対象OS、VBA7要件が明確か
2. `.bas`取込みと初心者向け実行順が再現可能か
3. VBA7／Office 32bitのAPI宣言と型が妥当か
4. VBA7／Office 64bitのAPI宣言と構造体配置が妥当か
5. `SOCKADDR_IN6`、`::1`、ポート、scope IDが妥当か
6. UDPのデータグラム境界、無応答、タイムアウトを正しく扱うか
7. 応答元IPv6アドレス、ポート、TraceIdを検証するか
8. エラー時もソケットとWinsockを後始末するか
9. Traceが追跡可能で、数式・秘密情報の記録を抑制するか
10. セキュリティ、制限、実機未確認範囲が明記されているか

## クロスレビューで修正した主な事項

| 指摘 | 判定 | 修正内容 |
|---|---|---|
| WSADATAのC `char`配列 | 修正 | Byte配列で表し、API前に32bit=400／64bit=408を検査 |
| 使用中ポートの共有 | 修正 | `SO_REUSEADDR`をやめ、`SO_EXCLUSIVEADDRUSE`で排他的にbind |
| 別Excelプロセスの寿命 | 修正 | Excel／Workbook参照をモジュール変数で保持し、明示終了マクロを追加 |
| UDP送信成功の誤解 | 文書 | `sendto`成功は相手受信を保証しないとREADME、コメント、試験へ記載 |
| 無期限の応答待ち | 修正 | クライアント受信・送信タイムアウトを5000msへ設定 |
| 偽の応答元 | 修正 | `recvfrom`が返すIPv6アドレス、ポート、scope IDを送信先と照合 |
| 応答の取り違え | 修正 | 応答TraceIdと要求TraceIdを照合 |
| 不正な要求TraceId | 修正 | 英数字・ハイフン、最大128文字だけをサーバーログへ採用 |
| Traceシート保護時の二次障害 | 修正 | `Debug.Print`を先行し、シート書込みをエラー隔離 |
| 数式としてのログ実行 | 修正 | A:Gを文字列形式にして`Value2`で記録 |
| UDPの既定Trace接頭辞 | 修正 | 誤っていた`TCP6`を`UDP6`へ変更 |
| 日本語コメントの文字化け | 文書 | CP932変換またはVBE貼付けをREADMEへ追加 |
| TCP／UDP版の同名マクロ | 文書 | 同じブックへ混在させない制約を明記 |
| 実機未確認の誤認 | 確認 | READMEとTESTINGで未確認のまま保持 |

## 実機で残る確認

- Office 32bitと64bitの両方でVBAProjectをコンパイル
- `CheckUdpIPv6StructureSizes`の成功
- `[::1]:60053`のHELLO、日本語ECHO、QUIT
- 受信側なしで約5秒後にタイムアウトすること
- ポート競合で2個目のbindが失敗すること
- サーバー専用Excelの起動・保持・終了
- 保護されたTraceシートでもWinsockが後始末されること

結果はOfficeのビット数、Windows／Excelのバージョン、Trace、Winsockエラー番号とともに追記してください。
